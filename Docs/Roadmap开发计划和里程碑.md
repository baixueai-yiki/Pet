## 未来计划的更新
# 1.设计一个新的Actor
GameActor（游戏对象）
用于在屏幕上模拟一个病娇小游戏
希望实现一种晴小姐从游戏里跑出来的效果
或是桌宠晴小姐偶尔会把玩家关起来
但总之想设计成晴小姐本身是二次元人物，桌宠本身就是晴小姐做的一个陪伴玩家的小程序而已
设计思路：
“囚禁”本身就是晴小姐与玩家之间的一种情趣play
晴小姐始终都爱着玩家，不会真的伤害玩家
需要参考《爱之巢》原作第一章和池池早期病娇互动视频：
【【互动游戏/病娇监禁预警】这是一个关于『爱』的故事】 https://www.bilibili.com/video/BV1T7411g7mk
灵感来源：
【小心电脑里的宠物狗！它会趁你不注意的时候跑出来！恐怖游戏《Play Pet || 玩宠物》游戏流程实况】 https://www.bilibili.com/video/BV1sVrwB2ELG

# 2.补充晴小姐获取玩家生日等信息的渠道
感觉这种功能可以模仿原作《爱之巢》一周目那样，在和晴小姐坐在一起聊天的时候获取信息
或许可以把这种功能都融入到模拟游戏里，就像早期晴的互动视频那样
在问答中获取玩家的信息，生日、爱吃的东西等
可能也是唯一获取玩家信息的渠道
这样或许可以引导玩家愿意和晴小姐进行囚禁play

# 3.尝试将用户生日与其他特殊日期的对话混合起来
现在把用户的生日设计成优先级最高的启动对话
但很多人的生日可能还在特殊的日子
而且我很期待有人和晴小姐生日在同一天
所以我希望之后可以优化一下生日的特殊对话
能够把文本及语音与特殊节日的结合起来

# 4.优化日记的文本与记录规则
现在晴小姐写的日记还是很生硬
而且这个功能本身我就没怎么完善
希望后续可以做两件事：
1.优化diary_script.txt里面晴小姐的文本
2.优化晴小姐写日记的文本组织规则
我希望文本的顺序是不固定的，希望文本当中包含了对于互动数据和晴小姐情绪的记录
希望日记内容有趣，玩家可以有兴趣看晴小姐的日记

# 5.优化晴小姐生理期与情绪以及行为
这部分功能可能比较诡异，正常人也不会给桌宠设计生理期
这里是用来调控晴小姐的行为，增添变化感
同时也是为了补充日记内容
希望后续可以为晴小姐的三种时期（上升期、下降期、生理期）
配置不同的情绪数值和变化规则
在增添日常互动新鲜感的同时也更灵活的调控日记内容

# 6.优化随机对话内容以及互动性
感觉现在的互动还是太少了，应该添加更多备选的随机语句
而且预期中的“玩家不吃饭晴小姐也不吃饭导致晴小姐健康下降”目前也没途径实现

# 7.为对话框和晴小姐本身补充美术素材
对话框和立绘是绑在一起的，需要做一些带有不同表情立绘的对话框
以及桌宠本身，至少该播放小动画才对
而且被点击也应该有反馈
不过我不知道怎么把游戏里的动画资源拿出来

# 8.优化晴小姐被拖动时的效果
目前发现拖动晴小姐时若鼠标移动过快，则晴小姐会跟不上鼠标
虽然也可以慢点拖动来解决，但考虑到有的人鼠标速度可能很快
所以应该修改这方面的逻辑，改为晴小姐始终都会瞬移或间隔瞬移到鼠标所在的位置

# 2026.4.3（回忆） Actor的设计
我承认这好像是没有意义的改动，但我个人确实觉得结构更清晰了
在与AI进行交流后，我设计了Actor对象
这是对我很喜欢的虚幻引擎的拙劣模仿
将负责业务逻辑的Systems系统层当中不同类型的功能块划分为了不同的Actor
并将每个Actor应有的功能和UI设计，划分成不同的Component和Panels挂载在Actor下面
或许这样能让人更清晰的理解桌宠的功能结构
（只是完全由AI写的代码可能一塌糊涂）
