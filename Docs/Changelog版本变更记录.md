## alpha内测版
# 1.0.alpha
窗口
1.铺满整个屏幕的全屏窗口
2.空白区域点击穿透
桌宠
1.右键晴小姐打开输入栏
    1.1.输入“我爱你”弹出关闭游戏的选项
2.左键单击 戳戳晴小姐
3.左键双击晴小姐打开功能栏
    3.1.设置栏，目前的设置项很多但几乎没用
    3.2.任务管理器，看起来晴小姐有能力关你游戏了
    3.3.歌曲，脑子抽风加入的功能，可以听池池唱歌
4.晴小姐偶尔会自动讲话
5.生理期与情绪模拟
    5.1.晴小姐有三个时期（上升期、下降期、生理期），和两种数值（兴奋值、愉悦值）
    5.2.晴小姐的时期天数影响兴奋值，兴奋值影响随机语句触发频率
    5.3.用户的行为会导致晴小姐作息不健康（用户12点还没睡，晴小姐熬不住了先睡觉自动关机），
    从而导致生理期紊乱（时期天数随机增减1）
日记
1.在程序运行期间会在diary_writing.txt里面写日记
2.在程序正常关闭时会把diary_writing.txt里的内容加在diary.txt后面
启动对话
1.对不同的对话情况进行优先级排列
    1.1.随机对话
    1.2.时间倒退，"嗯？时间倒退了...是我的错觉嘛？"
    1.3.非正常结束程序， "你上次，怎么突然从我面前消失了？"
    1.4.长时间不运行，"嘿嘿...好几天不见，我好想你！"
    1.5.特殊日期，"日记情人节快乐！"
    1.6.用户生日，"生日快乐哦~"
用户自定义
1.文本
    1.1.在chat_pet.json编写晴小姐的气泡对话和配置选项
    1.2.在chat_dialogue.json编写晴小姐的启动对话和配置选项
    1.3.在diary_script.txt编写晴小姐的日记文本
2.音频
    2.1.在chat_pet.json配置晴小姐的气泡对话语音
    2.2.在chat_dialogue.json配置晴小姐的启动对话语音
    2.3.也可以直接在audio文件夹当中修改音频
